# Processed Dataset Repository

This directory contains normalized, resized, and augmented images ready for train/val split.

## Preprocessing Pipeline
1. Image Normalization: Resized to 640x640 letterbox aspect ratio.
2. Motion Deblur: Wiener deconvolution for high-speed license plate recovery.
3. Contrast Enhancement: CLAHE (Contrast Limited Adaptive Histogram Equalization) applied to nighttime captures.
4. Auto-Labeling Validation: Pre-annotations generated by YOLOv8x and verified by human annotators.
